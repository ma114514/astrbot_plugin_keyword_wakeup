# 指定群关键词唤醒

让 AstrBot 在指定 QQ 群里听到关键词后，先判断这句话需不需要回答，再决定是否回复。

比如给机器人起名“小助手”：有人说“小助手，帮我解释一下这道题”，它可以回答；有人只是说“我昨天试了那个小助手”，它可以保持安静。具体怎么判断，由你填写的“判断规则”决定，结果也会受模型影响。

## 安装

需要 AstrBot **4.28.2 或更高的 4.x 版本**，通过 **aiocqhttp／OneBot v11** 连接 QQ，并且已经配置好聊天模型。

1. 打开 [v1.0.2 下载页面](https://github.com/ma114514/astrbot_plugin_keyword_wakeup/releases/tag/v1.0.2)，下载附件 **`astrbot_plugin_keyword_wakeup_v1.0.2.zip`**。
2. 在 AstrBot 管理面板的插件管理页面，使用本地 ZIP 安装入口上传这个文件。
3. 打开“指定群关键词唤醒”的设置，按下面的示例填写。
4. 保存配置，重载插件，并确认插件已启用。

下载时请选择插件 ZIP 附件，GitHub 自动生成的 `Source code` 是源码包。

也可以将安装包内的 `astrbot_plugin_keyword_wakeup` 文件夹放入 `data/plugins/`，然后重载插件。

## 第一次使用怎么填

假设你要在群 `123456789` 里，用“小助手”或“机器人”叫它：

| 设置项 | 填什么 |
| --- | --- |
| 允许关键词唤醒的群列表 | 添加一项，填写 `123456789`，换成你的实际群号 |
| 唤醒关键词 | 分别添加“小助手”和“机器人”，每项只填一个词 |
| 判断模型 | 可以先留空，使用这个会话当前的聊天模型 |
| 判断规则 | 可以先用默认内容，后面再改 |
| 历史群消息条数 | 保持默认的 `20` |
| 判断超时（秒） | 保持默认的 `15` |

群号直接填数字，不用填写带平台名称的完整会话标识。添加多个群或关键词时，每项单独填写，不要用逗号挤在同一项里。所有指定群共用这组关键词。

**群列表和关键词都要填。任意一个留空，插件都不会通过关键词唤醒。**

保存并重载后，到目标群里发一句：

> 小助手，帮我解释一下这道题。

不用 @，也不用加 `/`。插件会先请模型判断，判断需要回答后，再由 AstrBot 正常回复。

如果 AstrBot 开启了白名单，还要确保这个群在允许范围内。**AI 配置中的“额外唤醒前缀”需要留空**，否则只带关键词的消息仍可能无法触发回答。它对应 `provider_settings.wake_prefix`，与机器人平时使用的 `/` 等普通唤醒前缀不同，普通前缀无需删除。

## 想让它什么时候回答

“判断规则”就是告诉模型：遇到什么样的消息应该回答。你可以直接修改这段文字，不需要写代码或 JSON。

默认规则是：

> 结合群聊上下文，判断当前消息是否在呼叫机器人、向机器人提问或请求帮助。只是提及名字、转述或群友互聊时不回答；无法确定时不回答。

例如，只希望它回答天气问题，可以改成：

> 只有当前消息在向机器人询问天气时才回答。其他话题不回答，无法确定时也不回答。

**规则只在消息包含关键词时才会用到。** 即使群里有人问天气，没有出现你设置的关键词，也不会因为这条规则自动回复。

每次修改后，都要保存配置并重载插件。模型判断可能出现偏差，可以用群里的实际说法试几次，再调整规则。

## 其他设置怎么选

| 设置项 | 用法 |
| --- | --- |
| 判断模型 | 可以单独选一个模型来决定“要不要回答”。留空时，用当前会话的聊天模型；正式回答仍由 AstrBot 当前会话的模型完成 |
| 历史群消息条数 | 默认参考此前最近收到的 `20` 条群成员文本，帮助模型理解话题。可填 `0–100`；填 `0` 时只看当前这句话 |
| 判断超时（秒） | 默认最多等 `15` 秒，可填 `1–120`。超过时间还没得到判断结果，这条消息就不再通过关键词触发回复 |

历史消息只保存在内存里，重启、重载或停用插件后会清空，不会去补取之前的群聊记录。参考内容不含机器人自己的回复，也不会串到别的群或机器人账号。

每次符合关键词条件的消息通常会调用一次判断模型。判断通过后，再调用聊天模型正式回答，**两次调用都可能产生费用**。

## 常见问题

### 有关键词，为什么没回复？

包含关键词只是让模型开始判断，并不保证一定回复。先看看“判断规则”是否允许回答这句话，再检查下面这些地方：

- 群号和关键词是否填对，修改后是否保存并重载了插件。
- 当前群是否通过 AstrBot 的白名单检查，AI 聊天和插件是否都已启用。
- AI 的额外唤醒前缀是否留空，是否有其他插件限制群聊回复。
- AstrBot 日志里是否出现“判断超时”或“判断失败”。出现这些记录时，检查判断模型是否可用；必要时更换模型或增加等待时间。

模型没有按要求返回有效判断时，插件也会记录失败并保持安静，不会在群里发报错消息，也不会自动换一个模型重试。

### 配了 `Bot`，发 `bot` 能叫醒它吗？

不能。关键词区分大小写。需要两种写法时，把 `Bot` 和 `bot` 分别添加进去。

关键词按普通文字匹配，不支持正则表达式。例如 `.*` 只会匹配消息中实际出现的 `.*`。

### @ 它时，也会先判断吗？

不会。已有的 @、前缀等唤醒方式保持原样，可能直接回复。“判断规则”只影响这个插件新增的关键词唤醒。

### 叫醒一次，后面就可以一直聊吗？

本插件没有持续唤醒功能。后续每条消息仍需包含关键词，或使用 AstrBot 原有的 @、前缀等方式。

### 能在私聊里使用吗？

本插件只增加指定群的关键词唤醒，不改变私聊的回复方式。非指定群也仍按 AstrBot 原有配置处理。
